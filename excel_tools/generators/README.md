# generators/

Scripts that **create** Excel workbooks from scratch or from source data (CSV, JSON, dicts).

## Scripts
- `single_sheet_generator.py` — BEGINNER: read a CSV or JSON file and write a styled single-sheet .xlsx.
- `formatted_report.py` — INTERMEDIATE: build a report sheet with styled headers, auto-sized columns,
  conditional formatting on a numeric column, and a totals row.

New generators belong here if their primary job is producing a workbook, not transforming an existing one.
