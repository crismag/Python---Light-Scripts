# parsers/

Scripts that **read and extract** data from existing Excel workbooks.

## Scripts (planned)
- `sheet_reader.py` — read one or more sheets into Python dicts / DataFrames.
- `formula_extractor.py` — extract all cells containing formulas from a workbook.
- `named_range_parser.py` — list and resolve named ranges.

Use the `exports/` folder for scripts that write the extracted data to a different format (JSON, CSV, etc.).
