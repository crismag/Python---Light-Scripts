# transformers/

Scripts that **modify or combine** existing Excel workbooks — merging, splitting, reshaping, or rewriting sheets.

## Scripts
- `workbook_merge.py` — INTERMEDIATE: merge several .xlsx files into one workbook (one sheet per source file).

## Planned
- `sheet_splitter.py` — split a large sheet into one workbook per unique key value.
- `column_renamer.py` — rename columns in-place and save.
- `row_filter.py` — copy only rows matching a filter expression to a new workbook.
