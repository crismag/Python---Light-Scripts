# examples/

Sample datasets used by the scripts in this section as default demo inputs.

## Files
- `sample_sales.csv` — ~20 rows of regional sales data: date, region, product, units, unit_price, revenue.
- `sample_employees.json` — a JSON array of 15 employee records with realistic field diversity.

These files are intentionally small so scripts run instantly and outputs fit comfortably in a spreadsheet.
Feel free to replace them with larger real-world exports when testing at scale.
