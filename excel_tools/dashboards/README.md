# dashboards/

Scripts that **build multi-sheet, chart-equipped workbooks** intended for reporting or executive review.

## Scripts
- `dashboard_workbook.py` — ADVANCED: raw-data sheet + Summary sheet with aggregated KPIs and a bar chart.
- `executive_workbook.py` — SHOWCASE: polished executive workbook with a styled cover/KPI sheet,
  detail sheet, conditional formatting, and a chart — presentation-quality output.

## Planned
- `engineering_matrix.py` — generate a risk/effort matrix workbook with colour-coded cells.
- `summary_sheet_generator.py` — append a Summary sheet to any existing workbook.
