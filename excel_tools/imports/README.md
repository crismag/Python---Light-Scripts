# imports/

Scripts that **bring external data into Excel** — converting CSV, JSON, SQL results, or API responses
into .xlsx workbooks.

## Scripts
- `csv_to_excel.py` — BEGINNER: convert one or more CSV files into a single .xlsx workbook,
  one sheet per CSV file.

## Planned
- `json_to_excel.py` — convert a JSON array (or object of arrays) into a multi-sheet workbook.
- `sql_to_excel.py` — run a SQL query (SQLite/PostgreSQL) and write results to a sheet.
