# examples/

Sample data files used by all scripts in this section.

## Files

- **`sample_project.json`** — Realistic software-project summary (team, components, metrics, deps).
- **`sample_report.yaml`** — Multi-section engineering report spec used by `yaml_report_generator.py`.
- **`sample_inventory.csv`** — 20-host system inventory (hostname, role, cpu, ram_gb, os, status).
- **`sample_changelog.json`** — 5-release changelog with mixed change types for `changelog_generator.py`.
