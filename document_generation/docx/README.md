# docx/

Intermediate scripts that generate Microsoft Word (.docx) documents using python-docx.
No Office installation is required.

## Scripts

- **`docx_report.py`** — Generate a styled .docx report from a JSON project dataset.
  Produces a title page, key/value sections, and formatted tables for team, components,
  dependencies, and notes.  Header rows use navy-blue fills with white bold text.
