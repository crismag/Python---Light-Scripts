# html/

Showcase-level HTML report generation.  Output files are fully self-contained (embedded CSS).

## Scripts

- **`html_report.py`** — Generate a polished dashboard-style HTML report from a JSON, YAML, or
  CSV data file.  Features: embedded CSS, table of contents, summary stat cards, data tables,
  and an inline-SVG horizontal bar chart — zero JavaScript, zero external chart libraries.
