# converters/

Scripts that convert other file formats to or from PDF.

Planned scripts:
- `csv_to_pdf.py` — thin wrapper around table_report for CSV-specific defaults
- `json_to_pdf.py` — render arbitrary JSON structures as formatted PDF documents
- `markdown_to_pdf.py` — parse Markdown and render via reportlab Platypus
- `html_to_pdf.py` — convert an HTML file to PDF (requires weasyprint or xhtml2pdf)
