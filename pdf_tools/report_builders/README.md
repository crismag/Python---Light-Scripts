# report_builders/

Scripts that assemble advanced, multi-section PDF documents from structured data sources.

Scripts in this folder:
- `invoice_generator.py` — ADVANCED: styled invoice PDF from a JSON spec with seller/buyer, line items, and computed totals
- `engineering_report.py` — SHOWCASE: polished multi-section engineering report with cover page, TOC, data table, bar chart, and page-numbered footers
