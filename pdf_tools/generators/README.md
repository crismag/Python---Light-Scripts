# generators/

Scripts that create PDF files from scratch using reportlab.

Scripts in this folder:
- `simple_pdf.py` — BEGINNER: generate a basic PDF from a title and body text
- `table_report.py` — INTERMEDIATE: paginated table report from a CSV or JSON file
- `watermark.py` — INTERMEDIATE: stamp a diagonal text watermark across every page of an existing PDF
- `certificate_generator.py` — SHOWCASE: presentation-quality certificate PDF from CLI args or a JSON recipient list
